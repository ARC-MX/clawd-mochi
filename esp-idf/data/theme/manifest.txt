# Clawd Mochi theme — maps a device state to an animation file.
#
# Plain text on purpose: a theme can be edited on the device (or swapped
# wholesale) without rebuilding the firmware, and the parser stays trivial.
# Format: <state>=<file.caf>   ·   '#' starts a comment
#
# These are the states the Claude Code hooks drive:
#   idle          nothing happening
#   thinking      a prompt was submitted
#   working       a tool is running
#   done          the turn finished
#   error         something failed
#   sleep         idle for a long time
#
# The nap only starts from a resting state: while the panel is on `thinking` or
# `working` it does not fire at all, because a long tool call emits no hooks for
# minutes and dozing off in the middle of one is exactly what that rule is for.
# Those two names are spelled out in main.cpp (petIsWorking()) — renaming them
# here would quietly turn the rule off.
#
# The rest are spare art shipped with the theme; point any state at them by
# editing this file.

idle=clawd-headphones-groove.caf
thinking=clawd-thinking.caf
working=clawd-typing.caf
done=clawd-happy.caf
error=clawd-error.caf
sleep=clawd-sleeping.caf
